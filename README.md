# لوحة سيرفر ماين كرافت — استضافة تناوبية بين الأجهزة

عنوان واحد ثابت للاعبين، والاستضافة تتنقل بين جهازك وجهاز صاحبك بضغطة. مع كونسول حي، مراقبة موارد، إدارة مودات، ونسخ احتياطية.

```
اللاعبون → السيرفر الوسيط (VPS) → الجهاز المستضيف حاليًا
              الموزّع + اللوحة        جهازي أو جهاز صاحبي
```

## شو فيها

**الاستضافة**
- تحويل الاستضافة بين الأجهزة بدون تغيير العنوان
- ترفض التحويل لجهاز سيرفره مو شغّال، وتحذّر لو الهدف يسوي شغّال
- تحويل تلقائي عند انقطاع الجهاز المستضيف
- **دفتر عناوين محفوظة** لكل جهاز — احفظ الآيبي باسم وارجع له بضغطة
- تسجيل تلقائي لآخر آيبي اتصل منه كل جهاز

**التحكم بالسيرفر**
- تشغيل / إيقاف / إعادة تشغيل
- كونسول حي: أخطاء وتحذيرات ملوّنة، فلترة، بحث، تتبّع تلقائي
- إرسال أوامر بسجل أوامر (سهم فوق) وأوامر سريعة جاهزة
- إيقاف نظيف بأمر `stop` مع حفظ العالم، وإنهاء قسري لو ما استجاب

**المراقبة**
- معالج ورام السيرفر لحظيًا مع رسم بياني حي
- اللاعبون المتصلون، الإصدار، مدة التشغيل، زمن الإقلاع
- عدّاد أخطاء وتحذيرات
- حالة الجهاز نفسه: النظام، المعالج، الرام، حجم مجلد السيرفر

**المودات والإعدادات**
- عرض mods / plugins / datapacks
- تفعيل وتعطيل بدون حذف (إعادة تسمية `.disabled`)
- رفع بالسحب والإفلات، وحذف
- تعديل `server.properties` من اللوحة
- تعديل إعدادات التشغيل: الرام، مسار جافا، ملف الجار، التشغيل التلقائي

**النسخ الاحتياطية**
- نسخة مضغوطة (zip) للعوالم و`server.properties` و`ops.json`
- `save-all` قبل النسخ تلقائيًا
- عرض النسخ وأحجامها وحذفها

**الصلاحيات**

| | مالك | أدمن |
|---|---|---|
| تحويل الاستضافة | ✓ | ✓ |
| تشغيل/إيقاف السيرفر | ✓ | ✓ |
| الكونسول والأوامر | ✓ | ✓ |
| نسخة احتياطية | ✓ | ✓ |
| رفع/حذف/تعطيل مودات | ✓ | ✓ |
| تعديل الإعدادات | ✓ | ✗ |
| إضافة أجهزة ومستخدمين | ✓ | ✗ |

## التركيب

المتطلب: **Node.js 18+**. بدون أي مكتبات خارجية.

### على السيرفر الوسيط (VPS)

```bash
sudo apt update && sudo apt install -y nodejs
cd ~/mcpanel
node setup.js      # ينشئ حسابك والأجهزة والمفاتيح
node relay.js
```

افتح المنافذ:
```bash
sudo ufw allow 25565/tcp   # اللاعبون
sudo ufw allow 7000/tcp    # الأجهزة المستضيفة
sudo ufw allow 8080/tcp    # اللوحة
```

تشغيل دائم:
```bash
sudo tee /etc/systemd/system/mcpanel.service >/dev/null <<'EOF'
[Unit]
Description=MC Panel
After=network.target
[Service]
ExecStart=/usr/bin/node /home/USER/mcpanel/relay.js
WorkingDirectory=/home/USER/mcpanel
Restart=always
User=USER
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now mcpanel
```

### على كل جهاز مستضيف

انسخ `agent.js` للجهاز وشغّله:

```bash
node agent.js
```

بيسألك أول مرة عن: عنوان السيرفر الوسيط، معرّف الجهاز، المفتاح (من اللوحة → إدارة اللوحة → المفتاح)، مجلد السيرفر، مسار جافا، والرام. يحفظها في `agent.json`.

على ويندوز — ملف `agent.cmd`:
```
@echo off
node "%~dp0agent.js"
pause
```

**ما تحتاج تفتح أي منفذ في الراوتر.** الوكيل هو اللي يتصل بالسيرفر الوسيط.

## السيناريو

1. أنت برا جهازك طويل.
2. صاحبك يفتح اللوحة، يختار جهازه، ويضغط **تشغيل** — السيرفر يقلع عنده ويظهر في الكونسول.
3. يرجع لنظرة عامة، يضغط **استلم الاستضافة**.
4. اللاعبون يدخلون بنفس العنوان.

لو انقطع جهازك فجأة والتحويل التلقائي مفعّل، اللوحة تتولى الاستضافة محليًا.

## مزامنة العالم — أهم نقطة

اللوحة تتولى الاستضافة، لكن **ملفات العالم لازم تكون واحدة على الجهازين**.

استخدم **Syncthing** لمزامنة مجلد السيرفر بين الأجهزة. والقاعدة اللي ما تتكسر: **لا يشتغل السيرفر على جهازين بنفس الوقت.**

ترتيب التسليم:
1. الجهاز الحالي: **إيقاف** من اللوحة (ينتظر حفظ العالم).
2. انتظر Syncthing يوصل حالة Up to Date.
3. الجهاز الجديد: **تشغيل**.
4. **استلم الاستضافة**.

خذ نسخة احتياطية قبل أي تسليم.

## أمان

- كلمات المرور بـ scrypt، الجلسات كوكيز HttpOnly تنتهي بعد ١٢ ساعة، و٥ محاولات خاطئة توقف دقيقة.
- **اللوحة على HTTP.** لو بتفتحها من برا حطها خلف Caddy أو Nginx بشهادة TLS، أو ادخلها عبر نفق:
  ```bash
  ssh -L 8080:localhost:8080 user@vps
  ```
- مفاتيح الأجهزة في `config.json`. أي مفتاح تقدر تجدده من اللوحة (إدارة اللوحة → المفتاح → تجديد).
- الكونسول يعطي تحكم كامل بالسيرفر — لا تعطي حساب أدمن إلا لشخص تثق فيه.

## ملاحظات

- **آيبي اللاعبين**: سيرفر ماين كرافت بيشوف آيبي الموزّع الوسيط. لو سيرفرك Paper ومفعّلت `proxy-protocol`، حط `"proxyProtocol": true` للجهاز في `config.json`.
- **التأخير**: البيانات تمر بالوسيط، فاختر VPS قريب منكم.
- **الرفع**: سرعة رفع بيت المستضيف هي الحد الفعلي — تقريبًا ٥ Mbps تكفي ٥-١٠ لاعبين.
- **الواجهة**: React بدون خطوة بناء، تحمّل من `public/vendor/` (محلي بالكامل، بدون إنترنت). لو تبي تحدّث النسخة، حمّل بندل ESM جديد من esm.sh (`?bundle&dev`) وبدّل الملفات في `public/vendor/`.
- **مجلد السيرفر** لازم يحتوي `server.jar` و`eula.txt` فيه `eula=true` قبل أول تشغيل.
